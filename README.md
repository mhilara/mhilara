## Cómo trabajo

| | |
|---|---|
| **Todo por IaC** | El cambio entra por `git push` y lo aplica el pipeline. Nunca por consola |
| **Lectura por defecto** | El agente vive en un rol que no puede escribir. El freno es la IAM, no el prompt |
| **Una autorización por acción** | Escribir en producción exige un OK puntual. Borrar exige dos personas |
| **Verificar antes de declarar** | "No responde desde acá" no es "está caído". Nada es "arreglado" sin verlo en runtime |
| **Memoria con higiene** | Índice corto, detalle por tema, y borrar lo que resultó falso |
